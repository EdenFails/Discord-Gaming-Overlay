Settings

Window Background Opacity 40%
How dark the entire overlay background is.
Message Background Opacity 0%
How dark the background behind each message is.
Auto-Hide Chat
Fades the chat completely out when there is no activity.
Auto-Hide Delay (Seconds)
How many seconds to wait before hiding the chat.
Sync Deleted Messages
If turned on, when someone deletes a message in Discord, it will instantly vanish from the overlay too.
Show Text Chat Overlay
Displays text chat messages and input box.
Show Voice Chat Overlay
Displays connected voice channel members, speaking rings, and mute status.
Show Voice Event Notifications
Displays text alerts for joins, leaves, mutes, and deafens inside the Voice overlay.
Auto-Monitor Voice Channels
Automatically monitors and displays voice call members whenever you join any voice channel in Discord.
Text Chat Max Height (px)
Custom max height for the text message section when both text and voice are active.
Auto-Expand Voice Section
Automatically expands the voice section to fit all call members down to the bottom of your screen. Disables custom pixel height.
Voice Chat Max Height (px)
Custom max height for the voice members section when both text and voice are active.
Voice Member Sort Order
Who to prioritize at the top of the voice member list in large calls.
Display Monitor
Which screen to spawn the overlay on.
Screen Position
Toggle Visibility Hotkey
Keybind to completely hide/show the overlay. (Must use modifiers + exactly ONE normal key. E.g. Ctrl+Shift+H)
Toggle Typing Mode Hotkey
Keybind to start typing in the overlay. (Must use modifiers + exactly ONE normal key. E.g. Ctrl+Shift+Enter)
